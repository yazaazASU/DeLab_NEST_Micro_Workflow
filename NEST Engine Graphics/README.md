# NEST engine graphics

Approved graphics used by the current NEST map workspace, exported 28 November 2026.

- **Crystals.png**, **Cells.png**, **Corals.png**: individual transparent PNGs, using each engine's current idle frame.
- **Poses**: all 12 original frames per engine, numbered 01 to 12 in reading order.
- **Sprite sheets**: original 4-column, 3-row transparent animation sheets and available source notes.
- **assets.json**: source references, frame dimensions, idle-frame choices and hashes.

Images retain their native resolution and original colours/transparency. The app uses Crystals v3, Cells v2 and Corals v2. No older character versions are included. Original NEST assets were not changed.
