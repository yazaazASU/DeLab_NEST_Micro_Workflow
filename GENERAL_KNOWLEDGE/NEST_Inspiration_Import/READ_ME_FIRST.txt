NEST OPTIONAL INSPIRATION LIBRARY

Prepared for integration; NOT installed or active.

knowledge_records.jsonl separates attributed descriptions from assistant scenarios and commercial hypotheses. Source descriptions are catalog paraphrases, not independently verified facts. Original concepts are explicitly labeled.

retrieval_policy.json describes proposed controls. These controls are inert configuration until the actual NEST application implements and tests them. Merely importing these files does not enforce isolation.

Do not add this entire library to the system prompt, training set, GIS evidence table or scoring model. Store it in a separate optional namespace with purpose-based retrieval. Default is disabled.

The earlier user preferences (crazy, mega, not museums/resorts/housing) are deliberately not global NEST rules. Existing titles, project statuses and descriptive content retain their meaning.

Zero bias is not demonstrable. Compare enabled/disabled runs across unrelated briefs, check retrieved context and confirm identical site scores before activation.

Original visual atlas and catalog remain unchanged. Image URLs are references and require internet; no image files or rights are transferred.
